# Vidéos IA STFC Academy (TikTok)

Objectif : publier 7 vidéos courtes par semaine sur TikTok, en français, avec l'avatar HeyGen et la voix clonée du dirigeant.

## Décisions validées (17/11/2026)

| Sujet | Décision |
|---|---|
| Format | Vidéo verticale 9:16, 55 secondes au plus, avatar face caméra |
| Contenu | Thèmes tirés de `../publications/banque_themes.csv` ; une vidéo reprend le thème du post Facebook du jour |
| Formats vidéo | Histoire d'entreprise ≈ 4 par semaine, Cas du dirigeant (personnage fictif) ≈ 2 par semaine, Conseil express ≈ 1 par semaine |
| Entreprises citées | Entreprises célèbres autorisées en vidéo, avec faits sourcés et vérifiés. Les clients réels restent interdits |
| Outils | Gratuits pour commencer : HeyGen (offre gratuite), puis montage FFmpeg, Whisper et Remotion piloté par Claude Code sur le PC Windows |
| TikTok | Option « Contenu généré par IA » activée sur chaque vidéo |
| Appel à l'action | Le même que pour les posts Facebook, selon le pilier (voir `../publications/DECISIONS.md`) |

## Limites de l'offre gratuite HeyGen

D'après des sources tierces, à vérifier sur la page officielle :
- environ 3 vidéos par mois ;
- 1 minute maximum par vidéo ;
- 720p avec filigrane.

Cette offre permet de tester les 3 pilotes. Elle ne suffit pas pour 7 vidéos par semaine : il faudra trancher après les tests.
