# stratfocusconsulting
stratfocusconsulting (stfc) est un cabinet spécialisé dans l'accélération des pme ( petite et micro-entreprise ) et dans la performance commerciale et stratégie marketing

## STFC Academy : plateforme SaaS de formation en ligne

Plateforme 100 % en ligne de formation aux métiers de la performance commerciale, du marketing et de l'innovation, pour l'Afrique francophone.

| Dossier | Contenu |
|---|---|
| [`docs/cahier-de-conception.md`](docs/cahier-de-conception.md) | Script complet en 5 blocs : étude de marché, architecture fonctionnelle, parcours et tarifs, plan de contenu détaillé, stack technique et déploiement |
| [`app/`](app/) | La plateforme : serveur Node.js, interface apprenant, back-office, 24 modules rédigés, certificats PDF, paiement CinetPay |

Démarrage rapide :

```bash
cd app && npm install && npm start
```

Le guide technique complet (déploiement, sécurité, passage à Supabase, édition du contenu) se trouve dans [`app/README.md`](app/README.md).
