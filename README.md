## Règles de rangement

- Un nouveau projet va dans la famille qui lui correspond, dans un dossier à son nom (minuscules, mots séparés par des tirets).
- Chaque projet garde son propre `README.md` pour expliquer son contenu.
- Les documents clients suivent la charte de `01-identite-stfc/charte`.
